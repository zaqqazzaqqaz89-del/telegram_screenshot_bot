## 🚀 ШАГ 1: СОЗДАТЬ TELEGRAM БОТА (5 минут)

### 1.1 Откройте Telegram

- На телефоне или компьютере

### 1.2 Найдите @BotFather

- В поиске введите: `@BotFather`
- Откройте официального бота с синей галочкой

### 1.3 Создайте бота

Отправьте команды:

```
/newbot
```

**BotFather спросит:**
```
Alright, a new bot. How are we going to call it?
Please choose a name for your bot.
```

**Ответьте** (например):
```
My Screenshot Bot
```

**BotFather спросит:**
```
Good. Now let's choose a username for your bot.
It must end in 'bot'. Like this, for example: TetrisBot or tetris_bot.
```

**Ответьте** (например):
```
my_screenshot_bot
```

### 1.4 Сохраните токен

**BotFather пришлёт:**
```
Done! Congratulations on your new bot...

Use this token to access the HTTP API:
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

Keep your token secure...
```

✅ **СКОПИРУЙТЕ ЭТОТ ТОКЕН!** Он понадобится в шаге 3.

## 💻 ШАГ 2: ЗАГРУЗИТЬ КОД В GITHUB (10 минут)

### 2.1 Создайте аккаунт на GitHub (если нет)

### 2.3 Загрузите файлы

   - `config.py`

   - `.env.example`
   - `.gitignore`
3. Внизу страницы нажмите **Commit changes**

**Вариант B: Через Git (для опытных)**

```bash

## 🌐 ШАГ 3: РАЗВЕРНУТЬ НА RENDER (15 минут)

### 3.1 Создайте аккаунт на Render

1. Зайдите на [render.com](https://render.com)
2. Нажмите **Get Started** или **Sign Up**
3. Войдите через GitHub (удобнее) или Email

### 3.2 Подключите GitHub

1. На главной странице Render нажмите **New +**
2. Выберите **Web Service**
3. Нажмите **Connect GitHub** (если ещё не подключен)
4. Разрешите доступ к репозиториям

### 3.3 Выберите репозиторий

1. В списке найдите `telegram_screenshot_bot`
2. Нажмите **Connect**

### 3.4 Настройте сервис

**Заполните форму:**

#### Basic Settings:
```
Name: telegram-screenshot-bot
    (или любое другое имя)

Region: Frankfurt (EU Central)
    (или любой ближайший к вам)

Branch: main

Root Directory: 
    (оставьте ПУСТЫМ)

Runtime: Python 3
```

#### Build & Deploy:
```
Build Command: 
pip install -r requirements.txt && playwright install chromium

Start Command: 
python main.py

Instance Type: 
Free (или Starter за $7/месяц для 24/7 работы)
```

### 3.5 Добавьте токен бота

**Раздел Environment Variables:**

1. Нажмите **Add Environment Variable**
2. Заполните:
   ```
   Key: TELEGRAM_TOKEN
   Value: ваш_токен_от_BotFather
   ```
   (вставьте токен из шага 1.4)
3. Нажмите **Add**

### 3.6 Создайте сервис

1. Нажмите **Create Web Service** (внизу страницы)
2. Подождите 3-5 минут (идёт установка и запуск)

### 3.7 Проверьте логи

В разделе **Logs** должно появиться:

```

✅ Deploying...
✅ Running 'python main.py'
✅ ============================================================
✅ 🚀 Бот запущен в режиме WEBHOOK
✅ 📡 Webhook URL: https://ваш-сервис.onrender.com/webhook
✅ 🔌 Порт: 10000
✅ ============================================================
✅ Планировщик запущен

```

**2. Скриншот конкретной области:**
```

```

```
→ Нажмите "🔔 Включить"
→ Нажмите "⏰ Изменить время"
→ Введите время (например: `09:00`)

Готово! Каждый день в 09:00 UTC бот будет присылать скриншот.

### Как найти CSS-селектор:

1. Откройте сайт в браузере
2. Нажмите **F12** (DevTools)
3. Нажмите иконку "выбрать элемент" (стрелка)
4. Кликните на нужный элемент
5. В DevTools справа найдите:
   - `class="main-content"` → используйте `.main-content`
   - `id="sidebar"` → используйте `#sidebar`

## ❌ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: "Executable doesn't exist" (браузер не найден)

**Решение:** Используйте Docker

1. На Render откройте ваш сервис
2. **Settings** → **Environment**
3. Измените на: **Docker**
4. **Save Changes**
5. **Manual Deploy** → **Clear build cache & deploy**

После этого браузер будет работать 100%!

### Проблема 2: Бот не отвечает

**Проверьте:**

1. **Токен правильный?**
   - Render → Settings → Environment Variables
   - TELEGRAM_TOKEN должен быть без пробелов

2. **Сервис запущен?**
   - На Render должен быть зелёный статус
   - Если красный - смотрите логи

3. **Логи без ошибок?**
   - Render → Logs
   - Не должно быть ERROR

### Проблема 3: "Port scan timeout"

**Решение:** У вас старая версия файлов

1. Убедитесь что в `requirements.txt` написано:
   ```
   python-telegram-bot[webhooks]==21.8
   ```
   (важно `[webhooks]`!)

2. В `main.py` должно быть:
   ```python
   application.run_webhook(...)  # БЕЗ asyncio.run(...)
   ```

### Проблема 4: Бот создаёт скриншоты медленно

**Это нормально!**
- Первый скриншот: 10-15 секунд (запуск браузера)
- Последующие: 5-7 секунд

**Для ускорения:**
- Используйте Starter план ($7/месяц) вместо Free

# ⚡ БЫСТРАЯ ШПАРГАЛКА

## 🚀 ЗА 5 МИНУТ

### 1. Создать бота
```
Telegram → @BotFather → /newbot
→ Сохранить токен
```

### 2. GitHub
```
1. github.com → New repository
2. Upload files (все из архива)
```

### 3. Render
```
1. render.com → New + → Web Service
2. Connect repository
3. Settings:
   Build: pip install -r requirements.txt && playwright install chromium
   Start: python main.py
4. Environment: TELEGRAM_TOKEN=ваш_токен
5. Create Web Service
```

### 4. Готово!
```
Telegram → найти бота → /start
```

## 📋 ВАЖНЫЕ НАСТРОЙКИ

### Render Settings:
```
Type: Web Service
Runtime: Python 3
Build Command: pip install -r requirements.txt && playwright install chromium
Start Command: python main.py
Environment Variables:
  TELEGRAM_TOKEN = ваш_токен_от_BotFather
```

### Requirements.txt важно:
```
python-telegram-bot[webhooks]==21.8  ← обязательно [webhooks]
```

## 🔧 БЫСТРЫЕ ИСПРАВЛЕНИЯ

### Браузер не работает:
```
Render → Settings → Environment: Docker
```

### Бот не отвечает:
```
1. Проверить TELEGRAM_TOKEN
2. Посмотреть Logs на Render
3. Перезапустить (Manual Deploy)
```

### Port timeout:
```
Убедиться что:
- requirements.txt содержит [webhooks]
- main.py использует run_webhook БЕЗ asyncio.run
```

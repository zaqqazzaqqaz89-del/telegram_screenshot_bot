# Примеры использования Telegram Screenshot Bot

## 🎯 Популярные кейсы

### 1. Мониторинг цен на товары

**Задача:** Отслеживать цену товара на сайте магазина каждый день

```
/seturl https://www.amazon.com/dp/B08N5WRWNW
/setselector #corePrice_feature_div
/schedule
→ Включить
→ Изменить время → 09:00
```

Теперь каждый день в 12:00 по Москве (09:00 UTC) вы будете получать скриншот с ценой.

## 🔍 Частые CSS-селекторы

### По классу
```
.header
.content
.price-box
.article-title
```

### По ID
```
#main
#content
#price
```

### Комбинированные
```
div.container
article.post
span.price
```

### Вложенные
```
.main-content article
#sidebar .widget
```

### Атрибуты
```
[data-product-id="123"]
[class*="price"]
```

## ⏰ Полезные времена для расписания (UTC)

Для часового пояса МСК (UTC+3):

| Время МСК | Время UTC | Когда использовать |
|-----------|-----------|-------------------|
| 08:00 | 05:00 | Утренние новости |
| 09:00 | 06:00 | Начало рабочего дня |
| 12:00 | 09:00 | Дневные данные |
| 18:00 | 15:00 | Вечерние обновления |
| 21:00 | 18:00 | Итоги дня |
| 23:00 | 20:00 | Перед сном |

## 🛠 Продвинутые техники

### Скриншот после прокрутки

Для сайтов с lazy-loading контентом можно модифицировать `screenshot_service.py`:

```python
# В файле screenshot_service.py уже есть метод take_screenshot_with_scroll
# Вы можете его использовать, добавив соответствующую команду в main.py
```

### Множественные элементы

Если нужно захватить несколько элементов, используйте общий родительский селектор:

```
/setselector .container
```

Вместо попытки выбрать:
```
/setselector .item1, .item2, .item3  # Не сработает
```

## 💡 Советы по использованию

1. **Тестируйте селекторы** - сначала используйте `/screenshot`, затем настраивайте `/schedule`

2. **Используйте простые селекторы** - чем проще, тем надёжнее

3. **Проверяйте время** - помните про UTC

4. **Сохраняйте скриншоты** - важные скриншоты можно сохранять в Telegram в "Избранное"

5. **Несколько ботов** - можете создать несколько ботов для разных целей

---

## 🚫 Ограничения

- Не работает с сайтами, требующими авторизации
- Не работает с динамическим контентом, загружаемым через сложный JavaScript (в большинстве случаев)
- Селекторы могут перестать работать, если сайт изменит структуру
- Не подходит для CAPTCHA-защищённых страниц
